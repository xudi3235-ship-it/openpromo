# OpenPromo Insights — Revised Execution Roadmap

## Vision: From a Data Report to a Growth Engine

Our goal is to build an analytics experience that acts as a proactive growth partner for SMBs. We succeed if our users feel we are saving them time, helping them grow their business, and making it easy to see the value OpenPromo provides.

This isn't just a dashboard; it's an engagement loop. We will surface simple, clear insights, recommend the next best action, and connect those actions directly to our powerful content creation tools. We will celebrate their wins and guide them when they're stuck, turning data into momentum.

---

## Phased Execution Plan

### Phase 1: The Data Foundation (P0 - Sprints 1-3)

*Goal: Establish the core data models, APIs, and UI to track and display essential metrics. Provide value even with no user data.*

1.  **Model the Data for Success:**
    - Implement the core data tables required for P0:
      - `workspace_goals` & `workspace_goal_progress` to track user-defined goals.
      - `channel_benchmarks` to provide context and relative performance.
      - `posting_time_recommendations` for actionable advice.
    - Extend `content_metrics_snapshot` to include `link_clicks` and `profile_visits` as value proxies.

2.  **Build the Insight Aggregator:**
    - Create the nightly aggregation job to populate a materialized view (`workspace_insight_snapshots`). This is the engine that will power the entire UX, calculating funnel metrics, streaks, and narrative highlights.
    - For P0, this job will run on a schedule (e.g., nightly). Real-time events will be a future enhancement.

3.  **Develop Shared APIs & Hooks:**
    - Implement the necessary `/insights/*` API endpoints using oRPC.
    - Define shared DTOs in `packages/shared` and create corresponding React hooks in `dash/ui/src/queries/insights.ts` to ensure data consistency across the app.

4.  **Design for the "Zero-Data" State:**
    - Build the initial Insights UI shell (`InsightsPage`).
    - **Crucially, design the empty state to be valuable.** When a new user visits, we will use `channel_benchmarks` to show them what's possible (e.g., "Brands like you in the Fashion industry post 4 times a week. Let's set that as your first goal!"). This provides immediate value and clear direction.

### Phase 2: The Engagement Loop (P0 - Sprints 4-5)

*Goal: Turn data into action. Build the features that guide users, encourage good habits, and proactively communicate their progress.*

1.  **Launch Goal Setting & Streaks:**
    - Implement the goal-setting flow on the Home/Momentum surface.
    - Start with a "smart default" suggestion (e.g., "Keep your 2 posts/week cadence?") for one-tap setup.
    - Visualize progress with the `Goal progress rings` and `Streak tracker`.

2.  **Create the "Next Best Action" Queue:**
    - Build the queue on the Home surface that prompts users with high-impact tasks.
    - Sources for P0: Goal gaps ("Post 1 more time to hit your weekly goal!"), anomaly follow-ups ("This post is going viral—repurpose it!"), and inbox backlog.
    - Each action should deep-link into the relevant tool (Composer, Inbox).

3.  **Deliver Proactive Digests & Nudges:**
    - Create a weekly digest worker (email, Slack) that reads from the `workspace_insight_snapshots`.
    - **P0 Simplification:** Instead of a complex real-time event stream (`insight_events`), nudges (e.g., "Your streak is at risk!") will be calculated and sent as part of a scheduled job (e.g., daily or hourly) to reduce initial infrastructure complexity.

4.  **Generate the "AI Narrative":**
    - Implement the "Hero win card" on the Home surface.
    - **P0 Simplification:** The AI narrative will be generated using a robust templating system (e.g., "You reached 50% more accounts this week! Your post about {top_content_title} was a big hit."). This de-risks the feature while still providing a magical, personalized summary.

### Phase 3: Delight & Personalization (Post-P0)

*Goal: Evolve from a great tool to an indispensable partner. Deepen personalization, introduce experimentation, and celebrate user success more widely.*

1.  **Introduce the Experiment Lab:**
    - Implement the dedicated `content_experiments` data models.
    - Build the UI for tracking A/B tests on content, showing lift/confidence, and promoting winning variants into templates.

2.  **Strengthen Conversion Tracking:**
    - Move beyond simple click proxies.
    - Introduce a simple, self-serve tracking pixel for users to install on their websites.
    - Provide better UTM parameter support and guidance to automatically attribute conversions.

3.  **Amplify Personalization & Growth:**
    - Add celebratory badges, milestone emails, and shareable social cards.
    - Personalize "Next Best Action" recommendations based on past user behavior and industry trends.
    - Introduce automated "mini-challenges" to keep users engaged.

---

## Final User Experience Vision (P0)

-   **Home / Momentum Surface:**
    - **Hero Win Card:** AI-powered narrative summary of the week's wins.
    - **Goal Progress Rings:** Clear, visual tracking of cadence and reach goals.
    - **Next Best Action Queue:** A simple, prioritized list of what to do next.
-   **Insights Hub:**
    - **Narrative Header:** Top highlights and anomalies.
    - **Funnel Board:** Awareness → Engagement → Clicks → Conversions (using proxies) with benchmark comparisons.
    - **Channel Tabs:** Best posting times and top content per platform.
-   **Email / Slack / Notifications:**
    - **Weekly Digest:** A summary of the narrative and funnel view.
    - **Triggered Nudges:** Proactive alerts for at-risk streaks or breakout posts.

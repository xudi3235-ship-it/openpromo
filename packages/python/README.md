# Proof of Concept

This is a PoC for OpenPromo. We want an upstream service that ranks the trending viral videos on TikTok/other platforms, and it patternize and extracts these elements to a reusable templates.

Some resources

1. [TikTok trending channel](https://www.tiktok.com/channel/trending-now?lang=en)
2. there's also 3P apps like [TrendTok](https://apps.apple.com/us/app/trendtok-analytics-tracker/id1550778062?pt=122616179)
3. can also leverage [google trend api](https://trends.google.com/trending?geo=US)
4. really nice GH action based crawled data for TT: https://github.com/antiops/tiktok-trending-data

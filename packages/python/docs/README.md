# OpenPromo

@rayli09

Builting a production-ready pipeline for automated viral video generation for social media platforms.

## Components

1. ChatTTS, SOTA text to speech model.
2. FasterWhisper, transcription
3. [LivePortrait](https://github.com/KwaiVGI/LivePortrait), vid2vid
4. [LatentSync](https://github.com/bytedance/LatentSync), lip sync, open source
